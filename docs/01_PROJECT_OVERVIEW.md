# Project Overview

Project Name

Religious Affairs Management System (RAMS)

(Current name is temporary and may change in the future.)

---

## Project Type

Enterprise Grade Multi-Tenant SaaS Application

---

## Project Purpose

The purpose of this software is to digitally manage all religious activities inside an organization.

Instead of maintaining attendance and progress manually using paper or Excel sheets, all information will be managed through one centralized system.

The software must be extremely simple so that users with little or no technical knowledge can use it without training.

---

## Current Modules

The first release contains only two departments.

### 1. Quran Department

Responsible for

- Quran Teachers
- Quran Classes
- Quran Attendance
- Quran Progress
- Quran Reports

### 2. Salah Department

Responsible for

- Jamaats
- Jamaat Leaders
- Daily Salah Attendance
- Salah Reports
- Statistics

## Target Users

### Super Admin

Complete control over the SaaS platform.

Can create companies.

Can manage subscriptions.

Can manage all system settings.

---

### Company Admin

Controls only their own company.

Can manage employees.

Can manage teachers.

Can manage jamaats.

Can manage reports.

Can manage settings.

---

### Religious Affairs Admin

Responsible for all religious modules inside the company.

---

### Quran Teacher

Can only access assigned Quran classes.

Can manage attendance.

Can update Quran progress.

Cannot access administration settings.

---

### Jamaat Leader

Can only access assigned Jamaat.

Can submit five prayer attendance.

Cannot access other Jamaats.

---

### Employee

Can only view his own information (future module).

---

### HR

Can manage employee records.

Can generate reports.

Cannot modify religious settings unless permission is granted.

---

### Auditor

Read-only access.

Can generate reports.

Cannot modify data.
