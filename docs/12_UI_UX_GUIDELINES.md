# UI / UX Guidelines

## Objective

The system must be extremely simple and easy to use.

Most users will not be technical.

Some Quran Teachers cannot understand English.

Therefore the application must prioritize simplicity over complexity.

# Error Messages

Must be user friendly.

Never expose SQL errors.

Never expose Exception messages.

Example

Incorrect

SQLSTATE[23000]

Correct

Employee ID already exists.

---

# UI Standards

No page should require horizontal scrolling.

Forms should remain consistent throughout the system.

Icons should be consistent.

Spacing should remain consistent.

Typography should remain consistent.

Navigation should remain identical across all modules.
